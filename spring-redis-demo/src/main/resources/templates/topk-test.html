Redis TopK 测试页面

1. 初始化 TopK 结构 reserve






必须先初始化才能使用。topk 为保留的 TopK 容量，width/depth 为哈希表列数/行数，decay 为指数衰减因子（0~1）。

2. 添加元素 add



kickedItems 为本次添加后被"踢出"TopK 的元素列表（因指数衰减被淘汰）。

3. 批量累加计数 incrby






一次性为多个元素累加指定权重（相当于多次 add）。

4. 查询元素是否在 TopK query




inTopK 返回布尔列表，true 表示该元素当前在 TopK 中。

5. 查询元素估计访问次数 count




counts 返回各元素的估计频次（近似值，受衰减影响）。

6. 获取完整 TopK 列表 list


返回当前 TopK 中保留的所有元素（按频次排序）。
