Redis JSON 测试页面

1. 设置 JSON POST /json/set/{key}



2. 获取完整对象 GET /json/get/{key}


3. 按路径获取 GET /json/get/{key}/{path}



路径示例：$.name、$.price、$.tags、$.attr.color

4. 删除 JSON DELETE /json/del/{key}


5. 类型查询 GET /json/type/{key}/{path}



6. 对象字段数 GET /json/objLen/{key}


7. 对象字段名 GET /json/objKeys/{key}/{path}



8. 字符串长度 GET /json/strLen/{key}/{path}



9. 数组长度 GET /json/arrLen/{key}/{path}



10. 批量操作 GET /json/batch

通过 pipeline 批量写入 product:1001、product:1002，并为 product:1001 的 tags 追加"早餐"标签
